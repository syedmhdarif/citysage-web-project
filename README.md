# CitySage Web Project

**🔗 Live Demo:** [https://syedmhdarif.github.io/citysage-web-project/](https://syedmhdarif.github.io/citysage-web-project/)

> AI-powered urban intelligence platform for smart cities across Southeast Asia. Based in Kuala Lumpur, Malaysia, CitySage deploys specialised AI workers that help municipalities and developers make data-driven decisions for smarter, more sustainable urban development.

## 🌆 Overview

CitySage is a comprehensive smart city platform that combines:

- **🤖 AI Workers**: Domain-specific AI agents for urban challenges (C-Rose, C-Siti, C-Kimi, C-Ruma)
- **📊 Data Analytics**: Unified dashboards for transport, environment, and infrastructure data
- **🏙️ Smart City Consulting**: End-to-end advisory for municipalities transitioning to data-driven urban management
- **🔗 IoT Integration**: Connected sensors, cameras, and edge devices feeding actionable intelligence
- **🎓 Capacity Building**: Training programs through CitySage Academy

## 🚀 Key Features

### AI Workers
- **C-Rose**: Geospatial AI agent for satellite imagery and spatial analysis
- **C-Siti**: Urban planning and zoning optimisation specialist
- **C-Kimi**: Data governance and compliance expert
- **C-Ruma**: Housing affordability and community strategist

## 🛠️ Tech Stack

- **Framework**: Next.js 16 with React 19
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion & Lottie
- **TypeScript**: Full TypeScript support
- **Deployment**: GitHub Pages

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
